# Task 2 – Stock Portfolio Performance Tracker

## Description
A Python application that tracks stock investments and calculates portfolio performance based on purchase prices, quantities, and current prices.

## Features
- Enter stock ticker symbols
- Record purchase price and quantity
- Enter current stock prices manually
- Calculate the total investment value
- Calculate the current portfolio value
- Calculate profit or loss
- Generate a portfolio summary CSV file

## Technologies Used
- Python 3
- CSV file handling
- Basic financial calculations

## How to Run
1. Install Python 3.
2. Open a terminal in this folder.
3. Run:

```bash
python portfolio.py
```

## Note
Stock prices are entered manually. This application does not fetch real-time stock market prices.
